## It Was Tall 0.4.8 (beta)

### Fixes
- **Radio panel.** Everything now fits inside the frame: ON AIR, ON / OFF and the level meter keep a margin from the edges.
- **Walkie-talkie slot.** Uses the same leather frame as the rest of the HUD, with a red border while it is selected.

### Playing as It (god mode)
- **See yourself as It.** In third person (F5) you now see the tall body you are wearing, moving and turning with you. In first person it stays hidden so it does not block your view.

### NeoForge (unofficial)
- The mod can be run on **NeoForge 1.21.1** through **Sinytra Connector** (with Forgified Fabric API and GeckoLib for NeoForge). This is not tested by us, and the Simple Voice Chat features (walkie-talkie, radio voices, It copying voices) do not work there. Please report anything that breaks.
